# Topup & API Reseller Panel

Minimal, secure, full‑stack topup website with API reseller support.
Built with Flask, SQLite, Bootstrap 5, and Telegram bot integration.

## Features
- User registration / login (hashed passwords, CSRF protection)
- Deposit system via QR image + Telegram admin approval
- API key generation for resellers
- REST API endpoint to place orders automatically
- Automatic pricing with 3‑6% profit margin
- Admin panel (ban users, add balance, approve deposits, edit prices)
- Telegram notifications for deposits, orders, new users
- Modern dark UI, mobile‑responsive
